# CyberSecurity Second Brain

My personal knowledge base and study archive. As a cybersecurity student, I believe in the "Learn in Public" philosophy. This repository holds my structured Markdown notes covering everything from OS internals to industry security frameworks.

## Objective
To maintain a searchable, well-organized database of technical concepts, ensuring high retention and providing a reference guide for standard operating procedures.

## Core Domains Covered
* **/Windows-Internals:** Architecture, processes, threads, memory management, and Active Directory concepts.
* **/Linux-Architecture:** Core OS configurations, permission structures, and command-line mastery.
* **/Security-Frameworks:** OWASP Top 10 web vulnerabilities, NIST guidelines, and foundational CompTIA Security+ principles.
* **/Networking-Theory:** OSI model, routing, switching, and subnetting.

## Methodology
Notes are written in a problem-solution format, emphasizing *how* and *why* things work at the engineering level, rather than just memorizing definitions.
